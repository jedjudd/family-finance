Setup Instructions
1. Open Google Sheets → create a new spreadsheet
2. Click Extensions → Apps Script
3. Delete the existing code, paste the script from family-finance-sync.gs
4. Replace the SHARED_TOKEN value with a long random string (treat it like a password)
5. Click Deploy → New Deployment → Web App
6. Set Execute as: Me and Who has access: Anyone (NOT "Anyone with Google account")
7. Click Deploy → copy the URL → paste above, then paste the same token above
8. Both you and your wife open this HTML page and enter the same URL + token. No Google sign-in required.
